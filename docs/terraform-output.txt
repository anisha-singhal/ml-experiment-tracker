Other regions need no sweep: this account's policy denies every API call
outside ap-southeast-2, so nothing could have been created anywhere else.

One resource was refused during apply: iam:CreateOpenIDConnectProvider is
also denied by the account policy. That is the OIDC provider for IRSA
(pod-level IAM). It is not needed for the cluster, the node group or the
VPC, which all provisioned; it is why the EBS CSI add-on never became
ACTIVE, and the apply was stopped there and the stack destroyed.
