Everything else this project declares - VPC, subnets, IGW, NAT Gateway, EIP,
route tables, S3 endpoint, IAM roles - is supported, so the network applies for real.

Error: failed to refresh cached credentials, no EC2 IMDS role found,
operation error ec2imds: GetMetadata, request canceled, context deadline

The provider tried every credential source and found none. 169.254.169.254 is the EC2
instance metadata service - the LAST source in the chain - so this says 'nothing was
configured', not 'the configuration is broken'. plan needs credentials because it
REFRESHES: it asks AWS what exists before diffing. validate is offline.
